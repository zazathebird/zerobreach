# _deferred — not for this session

Reference material for the detection-module work package owned by the main session: the full
project rule book, the threat analysis document, and copies of the engine modules and their
tests used as style templates.

**Do not read these in a session working out of `fable-work/`.** Nothing in `tasks/` needs them.
They are large, they are dense, and none of the tasks in this package touch the code they
describe.

What you actually need is in `reference/`:

- `REPORT_DATA.md` — the shapes of every file the tasks read
- `LOADER_HELPERS.txt` — the helper functions available in the engine's scope
- `../CLAUDE.md` — the rules that apply to this package
